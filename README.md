# Ramzi Alashmali

Building AI/ML systems with Python, from video retrieval and computer vision to world-model research and streaming data pipelines.

I’m interested in how models fit into complete systems: preparing data, retrieving useful context, serving predictions, and making results understandable.

| Project | Focus | Implementation |

- **Data systems:** Kafka, PySpark, Delta Lake, and SQLite
- **Applications:** Python, FastAPI, Streamlit, TypeScript, and Next.js
